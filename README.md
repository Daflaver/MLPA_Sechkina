Домашнее задание 1. Реализованы в двух вариантах (Scalar и SIMD на AVX2) и для трех типов (`int32`, `float32`, `float64`):

- арифметика над массивами: `+`, `-`, `*`, `/`
- сумма и среднее значение
- функции активации SiLU и GELU (только `float32` и `float64`)
- умножение квадратных матриц `n x n`

В программе есть тесты на корректность и нагрузочные тесты. Результаты в [report.md](report.md).

## Структура

```
main.cpp         весь код
CMakeLists.txt   сборка
report.md        отчет с результатами и анализом
figs/            графики для отчета
```

## Требования

- процессор с поддержкой AVX2
- GCC (проверено на 11.4.0) или другой компилятор с поддержкой C++17, `-mavx2` и OpenMP
- CMake 3.10 или новее


## Сборка

```bash
mkdir build
cd build
cmake ..
make
```

Флаги сборки заданы в `CMakeLists.txt`: `-O3 -mavx2 -fno-tree-vectorize`. Флаг `-fno-tree-vectorize` выключает автовекторизацию.

## Запуск

```bash
./homework
```

Программа сначала запускает тесты на корректность (SIMD сравнивается со скалярной версией, пороги OpenMP на время тестов отключены), потом нагрузочные тесты.
Нагрузочные тесты проходят на 1 потоке и на максимальном числе потоков.

## Размеры данных

- массивы: `10^3`, `10^5`, `10^7` элементов
- матрицы: `64`, `256`, `512`

## Ограничения
- В AVX2 нет целочисленного деления, поэтому `int32` делится через `double`.
- `exp` для SiLU и GELU приближенный (ряд Тейлора), поэтому тесты сравнивают результат с допуском (`1e-3` для `float32`, `1e-6` для `float64`).
